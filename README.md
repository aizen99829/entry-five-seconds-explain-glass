An entry for the [make.fun](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949?utm_source=github&utm_medium=readme&utm_campaign=u-po-pu-five-seconds-to-explain-the-glass-934d9949) bounty **"Five Seconds to Explain the Glass"** ($2 total, top 8).

The task: in a single sentence of at most 200 characters, give a cat's
reason for knocking a glass off the table. No apology allowed. The
sentence has to be convincing, funny, and feel like a cat defending
itself in earnest -- one sentence only, no second line.


## The entry

> The glass had been eavesdropping on us for weeks, so before it could report back to the dog, I gave it a one-way trip to the floor.

131 characters, one sentence, zero apologies.

Why this defense stands out: it never reaches for the tired excuses --
gravity, curiosity, "it was already broken". Instead the cat reframes
the crime scene as a counter-espionage operation. The glass was a
listening device, the dog was its handler, and the shove was a
pre-emptive strike carried out for the good of the household. The cat
is not sorry; the cat is a whistleblower. That earnestness -- motive,
stakes, and total lack of remorse packed into a single breath -- is
what makes the line feel like a real cat talking, not a human writing
a joke about a cat.


## How it works

`main.py` is pure Python (no dependencies, no network calls). It holds
the sentence as a constant, validates it against the competition rules
-- exactly one sentence, at most 200 characters -- and writes it to
`/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

The program prints the sentence and its character count, so the
result can be checked at a glance before grading.


## Notes

The glass, for the record, never got its five seconds. It had weeks
to explain itself and said nothing -- which, in the cat's view, only
proves the charge. The floor has been informed and has no comment.
